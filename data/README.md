# KidneyCare source documents

Place the curated CKD educational PDF and plain-text source files used by the project in this directory.

The proposal calls for documents obtained in advance from authoritative healthcare sources such as CDC and NIDDK. Keep these files as static runtime inputs so the application does not require live website access.

For the final submission, document each source title, publisher, date when available, and URL. Do not add private medical records.
